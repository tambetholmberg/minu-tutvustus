# Minu tutvustus

Nooremtarkvaraarendaja kursuse esimene ülesanne: mind tutvustav HTML-leht.

## Sisu

Lehel on:

- minu nimi
- lühike tutvustus
- pilt
- minu hobid ja huvid
- link minu GitHubi kontole

## Failid

| Fail | Kirjeldus |
|------|-----------|
| `index.html` | Tutvustav leht |
| `tambet-kohv.png` | Lehel kasutatud pilt |

## Kuidas vaadata

Laadi repo alla ja ava `index.html` brauseris. Pilt peab olema `index.html`-iga samas kaustas.

## Kasutatud tehnoloogiad

- HTML5 (semantilised elemendid: `header`, `main`, `section`, `figure`, `footer`)
- CSS (lehe sees `<style>`-plokis)
