# Minu tutvustus

Nooremtarkvaraarendaja kursuse esimene ülesanne: mind tutvustav HTML-leht.

**Vaata lehte:** https://tambetholmberg.github.io/minu-tutvustus/

## Sisu

Lehel on:

- minu nimi
- lühike tutvustus
- pilt
- minu hobid ja huvid
- link minu GitHubi kontole

## Efektid (JavaScript)

- Nimi trükitakse lehe avamisel täht-tähelt nagu kirjutusmasinas, vilkuva kursoriga.
- Kursor kaob pärast nime valmimist ära.
- Seejärel ilmuvad lehe osad sujuvalt üksteise järel.
- Kui arvutis on animatsioonid välja lülitatud (`prefers-reduced-motion`), näidatakse lehte ilma efektideta.
- Kui JavaScript ei käivitu, on kogu sisu ikkagi kohe nähtav.

## Kuidas vaadata

Ava ülal olev GitHub Pagesi link või laadi repo alla ja ava `index.html` brauseris. Pilt peab olema `index.html`-iga samas kaustas.

## Kasutatud tehnoloogiad

- **HTML5** – semantilised elemendid: `header`, `main`, `section`, `figure`, `footer`
- **CSS** – lehe sees `<style>`-plokis, animatsioonid `transition` ja `@keyframes` abil
- **JavaScript** – lehe sees `<script>`-plokis
- **GitHub Pages** – lehe avaldamine
